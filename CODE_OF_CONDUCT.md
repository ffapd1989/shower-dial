# Code of conduct

Be kind, be specific, assume good faith. Criticise code, not people. Harassment,
discrimination and personal attacks are not welcome here, in issues, pull requests or
anywhere else this project lives.

If something happens, write to the maintainer through
[GitHub](https://github.com/ffapd1989). Reports are handled privately.
