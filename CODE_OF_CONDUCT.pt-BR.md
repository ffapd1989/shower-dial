# Código de conduta

Seja gentil, seja específico, presuma boa-fé. Critique o código, não as pessoas. Assédio,
discriminação e ataques pessoais não são bem-vindos aqui, em issues, pull requests ou
qualquer outro lugar em que este projeto viva.

Se algo acontecer, escreva ao mantenedor pelo
[GitHub](https://github.com/ffapd1989). Relatos são tratados em privado.
